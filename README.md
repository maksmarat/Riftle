# Riftle Classic

Статичный прототип угадывателя чемпионов в стиле LoLdle: один бесконечный классический режим, 8 параметров сравнения и сохранение текущего раунда в `localStorage`.

Интерфейс поддерживает English/Russian, выбранный язык тоже сохраняется в `localStorage`.

## Запуск локально

```bash
npm run start
```

Открой `http://localhost:4173`.

## Проверка

```bash
npm install
npx playwright install chromium
npm run test:smoke
```

## GitHub Pages

Сборка не нужна. В настройках Pages выбери деплой из ветки и корневую папку репозитория. Все пути относительные, поэтому сайт будет работать и в подпапке вида `/repo-name/`.

## Данные

Логика игры использует `data/champions.json`. Для нового режима можно добавить отдельный JSON рядом или расширить текущие поля, не трогая серверную часть.
